# Time-Based Encryption Project

A lightweight encryption project using timestamp, time zone offset, and random delay to produce a SHA-256 based key.  
Uses a simple XOR cipher for demonstration and learning.

## Run the Project

Use command : `python3 -m encription.main`
```
ayush@ayush-83eq:~/Desktop/encription$ cd ~/Desktop
python3 -m encription.main
Enter text to encrypt: Ayush

🔐 Encrypted: bytearray(b'\xcfk\xf5; ')
🔓 Decrypted: Ayush

    ```
